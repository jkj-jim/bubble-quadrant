# 飞书多维表格 - 气泡图插件

这是一个专为飞书多维表格仪表盘设计的自定义气泡图插件，可帮助用户通过可视化方式分析数据关系。

## 需求
我想在飞书多维表格的仪表盘上做一个气泡图的插件，让用户自选选择入参数据，自动生成相应的气泡图。
### MVP
- 完成基础的气泡图插件，可以正常在飞书多维表格的仪表盘上配置和保存
- 用户输入5个入参数据，都是下拉输入框，分别是「数据源」，对应气泡图的「气泡名称」、「横轴」、「纵轴」、「气泡大小」
    - 数据源：从当前多维表格中选择一个工作表作为数据源，必选
    - 气泡名称：从数据源中选择一个字段作为气泡的名称，非必选，如果选了则只显示有气泡名称的数据，如果为空，则显示所有数据
    - 横轴：从数据源中选择一个字段作为气泡图的横轴，必选
    - 纵轴：从数据源中选择一个字段作为气泡图的纵轴，必选
    - 气泡大小：从数据源中选择一个字段作为气泡的大小，非必选，如果选了则根据该字段的值来设置气泡的大小，如果为空，则所有气泡的大小相同
- 气泡图的显示规则
    - 轴标题显示为所选字段的字段名
    - 气泡名称相同的气泡，会重复显示
